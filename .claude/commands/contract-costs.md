```bash
npm run commissions -- contract-costs
```

For the accountant, not the rep. Deals of 12 months or less are expensed straight away under the practical expedient. Say this is a schedule for the accountant to review, not an accounting entry.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
