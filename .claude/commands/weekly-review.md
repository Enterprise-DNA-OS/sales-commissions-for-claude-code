Read CLAUDE.md first.

```bash
npm run commissions -- weekly-review
```

Five short sections: what blocks the next payroll, who is on track this month, what is owed, open disputes, compliance. One line each where possible. Write it to drafts/weekly-review-<date>.md if asked to keep it.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
