Read CLAUDE.md first.

```bash
npm run commissions -- record-super --payee="Ben Carter" --period=2026-09 --date=2026-10-09 --ref="Clearing house 4602" --actor="Leah Moore"
```

The date is when the fund received it, not when it was sent. Report the business days after payday and say plainly if it is over seven.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
