---
description: Show how far each rep is from quota and from the next rate band, with days left in the month.
---

Read CLAUDE.md first.

```bash
npm run commissions -- quota-gap
```

Turn it into one line per rep a sales manager can use in a one-on-one: "Ben needs $13,000 more to reach the 8% band, 20 days left."

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
