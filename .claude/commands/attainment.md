description: Show each rep against quota this month: credited sales, attainment, commission earned so far.
---

Read CLAUDE.md first.

```bash
npm run commissions -- attainment
```

Add --period=YYYY-MM for another month. Lead with who is above quota and who is under half, then the totals by currency. Never add NZD and AUD together.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
