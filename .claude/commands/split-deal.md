---
description: Set a rep's share of a deal (splits must add to 100% before the lock).
---

Read CLAUDE.md first.

```bash
npm run commissions -- split-deal --deal="Surry Hills" --payee="Ben Carter" --pct=60 --actor="Leah Moore"
```

Report the deal's total credited percentage after the change.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
